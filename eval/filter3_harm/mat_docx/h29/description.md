## Fig 4. Transient thermal impedance from junction to mounting base as a function of pulse duration; typical values

Type: log-log line graph, family of six curves, with an inset waveform diagram.
The whole plot sits inside a light-blue ruled frame.

- X: t_p (s), logarithmic, 10⁻⁶ to 1, labelled decades 10⁻⁶, 10⁻⁵, 10⁻⁴, 10⁻³,
  10⁻², 10⁻¹, 1. Axis caption "t_p (s)". Full log minor gridlines.
- Y: Z_th (j-mb) (K/W), logarithmic, 10⁻² to 10, labelled decades 10⁻², 10⁻¹, 1,
  10. Axis caption stacked at the upper left: "Z_th (j-mb)" over "(K/W)".
- Plot-ID string in the top-right corner of the plot: `003aad356`.

**Curve family.** Six curves labelled by duty cycle δ, all rising with pulse
duration and all converging onto the same horizontal asymptote at the right-hand
end. Labels are printed inline near the left edge, top to bottom:

| Label | Value at t_p = 10⁻⁶ s (read from axis) |
|---|---|
| δ = 0.5 | ~1.7 K/W |
| 0.2 | ~0.75 K/W |
| 0.1 | ~0.4 K/W |
| 0.05 | ~0.25 K/W |
| 0.02 | ~0.14 K/W |
| single shot | ~0.08 K/W |

All six curves merge at roughly t_p = 2 × 10⁻² s and run flat from there to
t_p = 1 s at a common plateau of ~3.1 K/W (read from axis) — the steady-state
R_th(j-mb) value given in Table 5 above the figure. The single-shot curve is the
steepest; each higher duty cycle starts higher and rises more gently.

**Inset** (boxed, lower right of the plot area): a small pulse-train sketch. A
vertical axis labelled **P**, a horizontal axis labelled **t**, and two rectangular
power pulses. The pulse width is dimensioned **t_p** and the pulse-to-pulse period
is dimensioned **T**. To the right of the waveform, the defining formula:

$$\delta = \frac{t_p}{T}$$
